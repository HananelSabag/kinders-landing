# 07 · שלושה עיצובים לבחירה

באתר החי יש שלושה עיצובים לאותו תוכן. העמותה עוברת ביניהם ובוחרת:
- **בדסקטופ:** ב-header, ליד כפתור התרומה: "גרסת דמו" באדום ושלושה כפתורים א ב ג
- **בנייד:** בתוך התפריט (☰), עם שמות העיצובים

אין פס טיוטה ואין כפתור צף, כדי שלא יפריעו לתוכן. הבחירה מופיעה רק כל עוד `isDraft: true` (`src/components/demo-switch.tsx`).

| | כתובת | בקצרה | גופנים | צבעים |
|---|---|---|---|---|
| **א · חם ומעוצב** | `/` | נייר ודיו. תגית מזוודה חרדל שנתלית, טופס התרומה בתוך התגית | Playpen Sans Hebrew + Assistant | נייר `#fff3eb`, דיו, חרדל, אלמוג |
| **ב · מונפש** | `/b` | "המסע": הצעצוע עובר את ארבע התחנות בזמן הגלילה | Fredoka (עם ציר רוחב) + Heebo | צהוב האגסים מהלוגו `#f8dea1` (רקעים), כחול כהה `#17384a`, ותכלת `#eaf4f6`. כתום רק במסגרת של התגית האמיתית |
| **ג · נקי וממוקד** | `/c` | בסגנון charity: water / GiveDirectly. כרטיס התרומה דבוק לצד התוכן בדסקטופ, ומיד אחרי הפתיחה בנייד | Rubik | לבן, דיו `#15202b`, כחול `#276b7a` |

## מה משותף (משנים פעם אחת, מתעדכן בשלושה)
- התוכן: `src/content/site.ts`
- התרומה: `src/app/actions.ts` + `src/lib/payments` (וואטסאפ היום). הלוגיקה של הטופס ב-`src/lib/use-donation.ts`, וכל עיצוב מצייר אותה אחרת
- הפוטר (`SiteFooter variant`), התפריט בנייד (`MobileMenu tone`), בחירת העיצוב, הכפתור הצף בנייד, הצהרת הנגישות ומדיניות הפרטיות

## עיצוב ב: מה זז ולמה
| איפה | מה קורה | בלי אנימציה |
|---|---|---|
| כותרת הפתיחה | המילים "מתנפחות" בזו אחר זו (CSS, ציר הרוחב של Fredoka) | הכותרת פשוט מופיעה |
| תמונת הפתיחה | החלון נפתח לכל הרוחב בגלילה הראשונה | תמונה ממוסגרת |
| התגית בפתיחה | מתנדנדת לפי מהירות הגלילה, כמו תגית על חוט | תגית תלויה |
| המספרים | עולים מאפס כשמגיעים אליהם | המספר הסופי |
| **איך זה עובד** (הרגע המרכזי) | אוספים: אפור ועקום ← מחדשים: חוזר לצבע, ברק ← עוטפים: צלופן, סרט ופפיון ← מעניקים: התגית נתלית | התמונה במצב הסופי והשלבים כרשימה |
| טופס התרומה | הבחירה "מחליקה" בין הסכומים, ההסבר מתחלף, הכפתור אומר כמה | אותם מצבים בלי תנועה |
| הסיפור | המילים נצבעות תוך כדי קריאה | טקסט מלא |
| הגלריה | שתי שורות שזזות לכיוונים מנוגדים בגלילה | שורות קבועות |

- ספרייה: **Motion** (`motion/react`), נטענת רק ב-`/b`
- `src/lib/use-motion-ok.ts`: בשרת ובטעינה הראשונה הדף תמיד במצב הסטטי והמלא. האנימציות נדלקות רק בדפדפן, ורק אם המשתמש לא ביקש "הפחתת תנועה"

## כשהעמותה בוחרת
1. מעבירים את העיצוב שנבחר ל-`/`: התוכן של `src/app/b/page.tsx` (או `c`) עובר ל-`src/app/page.tsx`, והגופנים מה-`layout.tsx` שלו עוברים ל-`src/app/layout.tsx`
2. מוחקים את התיקיות של מי שלא נבחר: `src/app/b`, `src/app/c`, `src/components/v-b`, `src/components/v-c` (ו/או `src/components/sections` של עיצוב א)
3. ב-`globals.css` מוחקים את הבלוקים "עיצוב ב" / "עיצוב ג" ואת הטוקנים `b-*` / `c-*` של מי שלא נבחר
4. מוחקים את `src/components/demo-switch.tsx` ואת השימושים בו ב-headers. אם ב' לא נבחר: `npm uninstall motion`
5. מעדכנים את `DESIGN.md` לעיצוב שנבחר
